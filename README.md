# Sát Hạch Lái Xe 2026 – Landing page

Trang giới thiệu và chính sách bảo mật cho ứng dụng iOS **Sát Hạch Lái Xe 2026**.

- `index.html` — Trang giới thiệu / Support URL
- `privacy.html` — Chính sách bảo mật / Privacy Policy URL

## Deploy (GitHub Pages)

Settings → Pages → Deploy from branch `main` / `/ (root)`.

- Support URL: `https://<username>.github.io/<repo>/`
- Privacy Policy URL: `https://<username>.github.io/<repo>/privacy.html`
